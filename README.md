# Brandon Church · portfolio

The third build of [brandonchurchportfolio.com](https://www.brandonchurchportfolio.com). In progress.

Preview: https://portfolio-website-v3-wheat.vercel.app

## Run it

```
npm install
npm run dev
```

Then open `http://127.0.0.1:5330`.

## How this repo is organised

| File | What it holds |
|---|---|
| `BRIEF.md` | What is being built and every decision made so far |
| `PLAN.md` | The order of the work and where it stands |
| `QUALITY.md` | The quality bar and how work is judged against it |
| `LOG.md` | Notes from each working session |
| `CLAUDE.md` | How Claude sessions work in this repo |

Built with Next.js, TypeScript, Three.js and GSAP.
